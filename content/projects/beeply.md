## Overview

Beeply connects mentees with mentors who actually fit their goals. Instead of simple keyword filters, it asks GPT-4o to judge how compatible each mentor is with a mentee and ranks the results.

## Features

- AI-powered compatibility scoring between mentees and mentors
- Matches ranked by score, and only strong matches above a 70% threshold are shown
- A React frontend backed by a Node.js/Express API

The source code for this project isn't public.
