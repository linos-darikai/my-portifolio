## Overview

Sika is a peer-to-peer lending web app built for Ashesi University students. Students can sign up as borrowers or lenders, request or offer small loans, and follow each loan from request through disbursement to final repayment.

## Features

- Sign-up with email verification codes and hashed passwords
- Separate borrower and lender dashboards, plus a user profile page with bank details
- Loan requests tagged by purpose (healthcare, transportation, recreation, charity, other) and duration
- Loan suggestions that match a borrower's request to open lender offers
- Loan lifecycle tracking: pending, approved, rejected, disbursed and settled
- Repayment schedules with paid, pending and late states, and a transaction log for releases and repayments

## Built with

Python and Flask on the backend, SQLAlchemy models over a MySQL database, and server-rendered Jinja templates with vanilla JavaScript and CSS on the frontend.
