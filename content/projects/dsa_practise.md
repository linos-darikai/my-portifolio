## Overview

A collection of data structures implemented from scratch in Java, each one applied to a small real-world problem instead of an abstract exercise.

## What's inside

- **Browser history:** a doubly linked list for back/forward navigation through visited pages, with timestamps and saving to a file
- **Music playlist:** three versions of a playlist, from basic to fully featured, built on linked nodes of songs
- **Contact list:** a binary search tree that keeps contacts sorted for fast lookup, insertion and deletion

## Built with

Plain Java, no libraries.
