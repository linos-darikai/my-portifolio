## Overview

Ubora is a desktop ticketing app for campus events. Attendees create an account, buy a ticket, and receive a digital ticket with a QR code that can be scanned at the door.

## Features

- Registration and login, with separate user types for students, faculty and guests
- Regular and VIP ticket options with payment details validation
- A unique QR code generated for every ticket using ZXing
- A ticket screen showing the event, seat, ticket type and QR code
- Tickets saved to CSV so they persist between sessions

## Built with

Java, JavaFX with FXML views and CSS styling, ZXing for QR codes, and Maven.
