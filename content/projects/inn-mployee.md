## Overview

Built during my software engineering internship at InnBucks Microbank, this app replaced a slow, paper-heavy onboarding process for new employees. It reduced HR onboarding time from three weeks to under four hours.

## Features

- A guided onboarding flow for new hires, designed in Figma first
- Modular onboarding steps that HR can configure themselves through admin controls
- Fewer change requests to engineering, since HR can update steps without code changes

## How it was shipped

Developed with GitHub Flow (feature branches, pull requests and conflict resolution), with core flows covered by unit and integration tests before release.

## Built with

Angular, TypeScript and Firebase.
